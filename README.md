# ErrorBuddy AI

Build a modern, developer-themed web app named 'ErrorBuddy AI' for beginner programming students. The UI should have a dark VS Code theme with sleek glassmorphism panels.

Page Layout: 1. Header: Logo named 'ErrorBuddy AI' with a green online dot, tagline 'Compiler Errors Explained in Simple Human Language'. 2. Input Panel (Left or Top): - Dropdown to select language: C, C++, Python, Java. - Text area for pasting Code / Error message with placeholder 'Paste your buggy code or error log here...'. - Primary Action Button: '⚡ Explain My Error Simply'. 3. Results Panel (Right or Bottom): - Card 1: '❌ What Went Wrong' (Easy English / Hinglish breakdown). - Card 2: '✅ Corrected Code' (Clean code block with a 'Copy Code' button). - Card 3: '💡 Pro Beginner Tip' (A helpful coding habit or syntax trick). 4. Add sample interactive demo buttons below input: 'Try Sample C Error (print vs printf)' and 'Try Sample Python Indentation Error' so clicking them auto-fills the input box for testing.
